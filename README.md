# XDA DSP Tuner

Bluetooth DSP app for Jensen XDA car amplifiers (XDA91RB / XDA92RB / XDA94RB / XDA95RB).

- 10-band graphic EQ + 6-band parametric EQ
- Crossover, bass boost, RGB, presets
- Official JLBT BLE protocol (`AE00` / `AE01` / `AE02`)
- Native iOS app in `ios-app/` (Ad Hoc IPA)

Signed IPA (iPhone 17 Pro Max): see Drive `XDA-DSP.ipa` or install via Safari:

https://cdn.jsdelivr.net/gh/bigrzz/xda-dsp-install@main/index.html
